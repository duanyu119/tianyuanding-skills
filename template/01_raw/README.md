# 01_raw — 原料层

## 规则

1. **永不修改** — 文件一旦放入，不重命名、不编辑、不删除
2. **保持原始格式** — PDF 就是 PDF，xlsx 就是 xlsx，不做格式转换
3. **命名规范** — `YYYY-MM-DD_来源_主题.ext`（例：`2026-01-15_律师_合同终版.pdf`）

## 什么文件该放这里

- 邮件附件（设计稿终版、产品提案定稿、外部报告）
- 合同终稿和关键过程稿
- 会议录音转录稿
- 第三方报告（行业数据、用户调研）
- 实验数据和测试结果
- 个人健康数据导出（体检报告、运动数据）

## 什么文件不该放这里

- 你自己写的分析和总结 → 放 `02_synthesis/`
- AI 生成的报告 → 放 `02_synthesis/`
- 临时工作草稿 → 放 `99_workspace/`
- 高敏感凭证（密码、token、密钥）→ 不要放进这个系统

## 为什么这么设计

原料层是整个系统的"真相档案"。所有上层的事实最终必须能追溯到这一层。如果原料被修改，追溯链就断了——你再也无法验证某条 baseline 事实的来源是否真实。
