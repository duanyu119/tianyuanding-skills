# 判断标注规则

## 目的

Baseline 同时承载事实和判断。事实可以溯源验证，判断取决于"谁说的"和"有多确定"。

不标注判断主体的后果：
1. 你的直觉判断和专家意见混在一起，被当成同等权重
2. AI 的推理被当成已确认事实，无人复核

## 标注格式

```
[判断: 主体, confidence]
```

示例：
```markdown
产品发布大概率在 Q3 [判断: 张总, high]
竞品 X 可能在 6 月前发布同类产品 [判断: AI, medium]
该方案的 ROI 预计 3-5 倍 [判断: 团队共识, medium]
```

## 判断主体（根据你的实际情况定义）

| 主体 | 说明 |
|------|------|
| [你的名字] | 你本人的判断、直觉、偏好 |
| AI | AI 的推理和判断 |
| [团队成员A] | 具体团队成员 |
| [外部顾问] | 律师/审计师/顾问 |
| 共识 | 多方讨论后的共识 |

## Confidence 等级

| 等级 | 含义 |
|------|------|
| high | 有直接证据或专业权威判断 |
| medium | 有间接证据，存在不确定性 |
| low | 推测性判断，证据不足 |
| speculative | 纯推演，仅供思考 |

## 适用范围

标注适用于 `03_baseline/` 中的：概率估计、风险评级、策略建议、时间线预判、主观评价。

不需要标注：可溯源的客观事实、日期金额等纯数据、直接引用文件原文。

## AI 判断的特别规则

AI 在 baseline 中新增判断时：
- 必须标注 `[判断: AI, confidence]`
- 如果 confidence 为 medium 或以下，同时标注 `[需补全]`
