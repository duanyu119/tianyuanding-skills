# System Status 规则

## 目的

Status dashboard 用来判断知识系统是否健康到"可以被信任"。

快速回答一个问题：今天能不能基于当前 baseline 做决策？

## Status 位置

`00_system/generated/SYSTEM_STATUS.md`

## Dashboard 结构

```markdown
# System Status

Last updated: YYYY-MM-DD HH:MM
Generated by: <tool or assistant>

## Overall

Status: green | yellow | red
Reason: one sentence.

## Sync & Backup

- Local: ok | warning
- Git remote: last push date, branch status

## Raw Integrity

- Total raw files:
- New (unprocessed):
- Modified (unexpected):

## Proposal Queue

- Draft:
- Awaiting approval:
- Approved not applied:

## Baseline Freshness

- Stale T1 files (>7 days):
- Stale T2 files (>30 days):
- Fields marked [需补全]:

## Next Actions

1. ...
2. ...
```

## 状态颜色

**Green**：无已知问题，T1 文件在有效期内，近期有成功备份。

**Yellow**：有同步 warning，或有 proposal 等待处理，或 T2 文件过期。

**Red**：baseline 源头链断裂、关键 baseline 过期或互相矛盾、备份冲突。

## 信任规则

如果 status 是 red，AI 在回答决策问题前必须先说明。
